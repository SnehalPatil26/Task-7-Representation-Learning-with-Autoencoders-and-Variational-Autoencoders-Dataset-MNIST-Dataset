## Objective

To learn compact feature representations and perform image compression using Autoencoders and Variational Autoencoders (VAE).

## Dataset

**MNIST Dataset**

The MNIST dataset contains grayscale images of handwritten digits from 0 to 9. Each image has a size of 28 × 28 pixels.

## Approach

* Design and implement an Autoencoder.
* Compress and reconstruct MNIST images.
* Implement a Variational Autoencoder (VAE).
* Analyze latent space representations.
* Compare reconstruction quality and compression efficiency.
